プライバシーポリシー

一般社団法人DevelopersHub（以下「当団体」）は、当団体のウェブサイト、および当団体が提供するアプリ「Dub」 （Web 版・iOS / Android / デスクトップアプリを含みます。以下「本サービス」）において取得する個人情報を、 以下の方針に基づき適切に取り扱います。

1. 事業者

一般社団法人DevelopersHub
連絡先: info@developershub.jp

2. 取得する情報

ウェブサイトのお問い合わせフォーム

  • お名前、メールアドレス、お問い合わせ内容
  • スパム対策のための認証情報

本サービス（Dub）

  • アカウント情報: 氏名、メールアドレス、プロフィール、所属・役割などのメンバー情報
  • 利用者が投稿・登録した内容: チャットのメッセージ、タスク、イベント情報、アップロード・共有したファイルなど
  • 通知のための端末情報: プッシュ通知用のデバイストークン、端末の OS 種別
  • 利用ログ: アクセス日時、IP アドレス、ブラウザ・端末の情報、エラー情報
  • 外部サービス連携: 利用者が Google カレンダー等の外部サービスとの連携を有効にした場合、連携に必要な範囲の情報

本サービスは利用にログインが必要です。アプリの Face ID / Touch ID 等による生体認証は端末の OS 内で処理され、 当団体が生体情報を取得することはありません。アプリに保存するログイン情報は端末内の安全な領域 （iOS ではキーチェーン）にのみ保存され、当団体には送信されません。

3. 利用目的

  • お問い合わせへの回答・ご連絡、スポンサーに関するご案内
  • 本サービスの提供（ログイン・本人確認、メンバー間のコミュニケーション、ファイル共有、タスク・イベント管理など）
  • 新着メッセージ等のプッシュ通知・メール通知の送信
  • 不正利用の防止、障害対応、セキュリティの確保
  • 本サービスの改善

当団体は、取得した情報を広告目的のトラッキングに利用したり、第三者に販売したりすることはありません。

4. 外部サービスの利用（委託）

本サービスの提供のため、以下の事業者のサービスを利用し、必要な範囲で情報を取り扱わせることがあります。

  • Cloudflare, Inc.（サーバー・データ保管、スパム対策）
  • Google LLC（Firebase Cloud Messaging によるプッシュ通知配信、利用者が連携した Google サービス）
  • Apple Inc.（Apple Push Notification service によるプッシュ通知配信）
  • Resend（メール送信）

5. 第三者提供

法令に基づく場合および前項の委託の場合を除き、ご本人の同意なく個人情報を第三者へ提供することはありません。

6. 保管と削除

個人情報は利用目的の達成に必要な期間保管し、不要となったものは削除します。 アカウントや投稿内容の削除、個人情報の開示・訂正・利用停止をご希望の場合は、 ご登録のメールアドレスから info@developershub.jp までご連絡ください。 ご本人であることを確認したうえで、法令に従い速やかに対応します。

7. 安全管理

当団体は、取得した個人情報への不正アクセス、漏えい、改ざん等を防ぐため、通信の暗号化やアクセス権限の管理など必要な安全管理措置を講じます。

8. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更することがあります。重要な変更がある場合は、本ページまたは本サービス上でお知らせします。

9. お問い合わせ

個人情報の取り扱いに関するお問い合わせは、info@developershub.jp までご連絡ください。
