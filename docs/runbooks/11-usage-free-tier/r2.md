# R2（`r2_storage` / `r2_class_a_month` / `r2_class_b_month`）

[← 一覧](./README.md) ・ 無料枠: **保存 10 GB-月・Class A（書き込み・一覧）100 万/月・Class B（読み取り）1,000 万/月**・月初（UTC）リセット。

## よくある原因

- 保存: 生 webhook（`dub-r2-webhook-raw`）・添付・画像を消さずにためている
- Class A: 小さいファイルを大量に PUT する・LIST を毎回呼ぶ
- Class B: 同じオブジェクトを何度も GET / HEAD する（キャッシュしていない）

## 使っている所の調べ方

操作の内訳（月初から。`s` / `e` は日付）:

```graphql
query($a:String!,$s:Date!,$e:Date!){viewer{accounts(filter:{accountTag:$a}){
  r2OperationsAdaptiveGroups(limit:1000,filter:{date_geq:$s,date_leq:$e}){
    sum{requests} dimensions{bucketName actionType}
  }
}}}
```

bucket 別の大きさ:

```graphql
query($a:String!,$s:Date!,$e:Date!){viewer{accounts(filter:{accountTag:$a}){
  r2StorageAdaptiveGroups(limit:1000,filter:{date_geq:$s,date_leq:$e}){
    max{payloadSize objectCount} dimensions{bucketName}
  }
}}}
```

Class A = `PutObject` `CopyObject` `ListObjects` `CreateMultipartUpload` など、Class B = `GetObject` `HeadObject` など。

## 対策

1. 保存: ライフサイクルルールで一定日数後に消す（`wrangler r2 bucket lifecycle add`）・不要なオブジェクトを消す・画像は縮小して保存
2. Class A: 小さいファイルはまとめて 1 つにする・LIST の結果をキャッシュする
3. Class B: 公開してよいものはカスタムドメイン + キャッシュで返す（キャッシュから返した分は数えない）

## 課金が正しい時

- 保存が利用者のファイル（ドライブ・添付）で、消せない

**R2 は月額の契約が無い**。支払い方法を登録すると、無料枠を超えた分だけ請求される:
保存 $0.015/GB-月、Class A $4.50/100 万、Class B $0.36/100 万（2026 年）。上限で止まらなくなる。
